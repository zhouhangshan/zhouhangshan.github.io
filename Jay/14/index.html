04Local Network

No server.
No account.
Same room.

Saltline supports two-player co-op over your LAN, directly between browsers. The host owns the machines, the relays and the mission state. The guest brings another gun.

01

Open the game

Both operators open the same saltline.html on devices connected to the same Wi-Fi or wired LAN.

02

Exchange a link code

Host a room, send the invite code to your partner. They paste it, generate a reply, and send it back.

03

Breach together

Connect, start co-op, and click the viewport once to capture the mouse. The boat takes both of you.
